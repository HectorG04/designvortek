Tome — dark sections (used sparingly)

PREMIUM ART COMMISSIONS · SINCE 2022

Used 2–3 times per page, never as default.

Reserve dark sections for hero blocks and CTA closers — like flipping to a dramatic page in an old book. The cream text on warm leather feels right; flat black would feel cold.

tome-950 #1A130C tome-900 #251A10 tome-800 #3A2A1C gold-glow #D4A24C
Rules
  • Page background is always parchment-50. Cards / elevated surfaces are parchment-100.
  • Primary text is always ink-900 or ink-700 (4.5:1 minimum contrast on parchment).
  • Burgundy is the CTA color. Gold is for accents, never primary CTAs (except hero gold-accent button).
  • Forest green appears sparingly — success states and the occasional service card.

Rules
  • One H1 per page. Always display-lg or display-xl.

04 · Foundations

Motion

Pages "unfurl" rather than slam. Restraint over flair — we use motion to direct attention, never to perform.

TokenDurationEasingUsed for
motion-fast150msease-outHover state, color transitions
motion-default250msease-outMost UI transitions
motion-slow400msease-softSection reveals, modals
motion-reveal600msease-softHero text staggers
Principles
  • Hover lift — cards rise 2–4px, gain subtle shadow + faint gold border.
  • Click feedback — buttons scale to 0.98 on :active.
  • Section reveals — fade + 20px translate-up. Trigger once. Never replay.
  • Stagger — 80–120ms between siblings.
  • No infinite animations except gentle ambient gradient orbs in hero (8–10s) and skeleton shimmer.
  • Respect prefers-reduced-motion — disable scroll animations, keep functional ones.

Decorative motifs

Two signature flourishes — used consistently rather than mixing five. They give the brand its TTRPG soul without tipping into RPG-character-sheet territory.

01 · Compass rose divider

Used between major sections instead of plain <hr>. SVG glyph at 24px, gold-500 on parchment.

02 · Gold corner flourish
Featured commission

Four 24px SVG corners on featured portfolio cards. Appear on hover (fade + slight outward translate).

03 · Drop cap (long-form only)

The first paragraph of a blog article opens with a Cormorant italic capital, 4 lines tall, gold-700. Used exclusively in /blog/[slug] — never on marketing pages, never in cards.

Cormorant italic, 4-line drop, gold-700. Padding-right keeps body text from kissing the cap.

Explicitly NOT in the system
  • Fleur-de-lis bullet points
  • Rune-style numerals for stats
  • Hand-drawn Caveat underlines under accent text
  • Aged-paper texture as primary background (3% overlay on cards only)
  • Scroll-shaped buttons, dice as bullets, ornate borders

Each was tempting. Each, deployed, would tip the brand into RPG-character-sheet territory. We're going Forbes-profile-of-a-master-illuminator, not Skyrim UI.

Slot availability widget

The brand's signature component. Honest, scarce, never aggressive. Filled = booked (burgundy with check). Open = outlined, gently pulsing. Shown in compact and full form.

AVAILABILITY

May 2026

2 of 5 open
3 of 5 slots booked · 2 remaining
AVAILABILITY

June 2026

Fully booked
Waitlist of 4 · we'll reach out if a slot frees up
Behavior
  • Open slot pulses gently at 1.0 → 1.05 scale, 1.5s loop. Stops on hover.
  • Hover open — scale 1.1, cursor pointer, tooltip "Click to reserve".
  • Click open — opens reservation modal with brief form (name, email, service, notes).
  • Booked slots are non-interactive. No click. No hover.
  • On the /availability page, show 3 months side-by-side. On homepage, show current month only.

For Claude Code & the Next.js build

Notes specifically for the engineering pass. Every visual decision in this document is grounded in the brief and is buildable in Next.js 16 / Tailwind v4 / Framer Motion without surprises.

Tokens → Tailwind v4

All design tokens live in tokens.css as CSS custom properties. Map directly to Tailwind v4 @theme in app/globals.css:

@theme {
  --color-parchment-50:  #FBF6E9;
  --color-burgundy-700:  #6B1F2A;
  --color-gold-500:      #C9A04A;
  --font-display: "Cormorant Garamond", serif;
  --font-body:    "Inter", system-ui, sans-serif;
  /* …all others from tokens.css */
}

Fonts

Use next/font/google for Cormorant Garamond + Inter + Caveat. Set them as CSS variables so Tailwind picks them up:

import { Cormorant_Garamond, Inter, Caveat } from "next/font/google";

const cormorant = Cormorant_Garamond({
  subsets: ["latin"],
  weight: ["400","500","600","700"],
  style: ["normal","italic"],
  variable: "--font-display",
});
const inter = Inter({ subsets:["latin"], weight:["400","500","600","700"], variable:"--font-body" });
const caveat = Caveat({ subsets:["latin"], weight:["400","700"], variable:"--font-accent" });

Recommended libs

  • Framer Motion — section reveals, hover lifts, slot pulse, modal enter/exit
  • Radix UI — Dialog, DropdownMenu, Tabs, Toast (skin them to brand)
  • Lucide React — all icons. Stroke width 1.5 globally.
  • Tiptap or Lexical — blog editor in admin
  • react-hook-form + zod — multi-step order form validation
  • next/image — everywhere. WebP + lazy-load below fold.
